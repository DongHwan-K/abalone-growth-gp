## Manifest and verification

- [`manifest.csv`](manifest.csv): size, SHA-256, script, source function and input of every figure, table and text file.
- [`validation/manuscript_comparison.csv`](validation/manuscript_comparison.csv): every number printed in Tables 1–5 and Figures 2, 4 and 5 of the manuscript against the regenerated value at the printed precision.
- [`validation/run_checks.csv`](validation/run_checks.csv): source checksum, checkpoint reuse, output completeness, separate-process runs of the numbered scripts, and package versions of the run.
- [`validation/figure_checks.csv`](validation/figure_checks.csv): Figures 1–3 design counts, correlations against the reference values and text format; Figures 4–6 drawn values against the internal calculations and the stacked mixture median, and the absence of the labels `conformal` and `gamma_0`.
- [`validation/table_comparison.csv`](validation/table_comparison.csv): every written table and text CSV against its in-memory builder and against the separate-process run of its numbered script (column names, row order, strings, and numbers at `rtol = 0`, `atol = 1e-10`).
- [`validation/table_mismatches.csv`](validation/table_mismatches.csv): every differing cell (header only when there is none).

Further supplementary outputs (growth-curve parameters, facility-level MAPE, residual-normality statistics, ablation detail) are written by `python abalone_median.py` to `abalone_paper_results/point_median/`.
